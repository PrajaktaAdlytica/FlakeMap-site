# Motion plan

| Page / section | Purpose and trigger | Visible behavior | Reverse / alternative |
|---|---|---|---|
| Home hero | Orient buyer; initial entrance + scroll | Typography settles; glass material moves slightly on desktop; step buttons update note | No blocking intro; static asset/text on reduced motion |
| Home horizontal story | Trace one task; desktop scroll or chapter controls | Baseline → timeout → eight runs → reviewed mock gate | Scrub reverses with up-scroll; Skip leaves; stacked below 1000px or 740px height |
| Product suite | Introduce all five directions; section enters / hover | Panels rise subtly; borders deepen and arrows turn | Still content readable; page links always available |
| Diagnostic flip | Relate event order to artifact; hover/click/tap | Front timeline, back acceptance evidence | Click pins; Escape returns; reduced motion switches faces without rotation |
| Workbench | Inspect the artifact; native selectors/actions | Version/condition/seed update totals and artifacts; review updates mock gate | Scroll never changes decision; reset restores timeout104 |
| Existing-stack fit | Clarify relation; stack selector | Tool-specific context changes within proposed fixture path | Explicit controls; no integration animation claims |
| Module pages | Explain input/output; workflow buttons | One selected stage and output caption | Four native buttons; full list always visible |
| Solutions | Clarify ownership; persona selector | Buyer job and relevant module links change | Native selected controls; no auto carousel |
| Evaluation | Show denominator; condition selector | Eight labeled outcomes and exact counts change | Text and caption retained; duration table available |
| Diagrams | Keep detail legible; small viewport | Scroll inside diagram panel; description disclosure | No document overflow; keyboard-focusable region |
| Forms/legal | Careful reading and completion | Validation, review/edit, reset, local completion | No parallax or decorative movement |
| Footer | Full information access | Social pending state; explicit motion control | No real profile URLs invented |
| Public content sections | Enter or re-enter the viewport | Compositions alternate left, up, right, and down entrances | Up-scroll re-entry reverses the entrance vector; reduced motion is fully visible |
| Inner-page heroes | Initial entrance and explicit controls | Platform evidence map, solutions ownership diagram, pricing week selector, resources editorial cover, company evidence principles | Each hero stacks on narrow screens; controls remain keyboard accessible |
| Demo stats | Select normal, timeout, or delay | Baseline, candidate, and duplicate-run counts update with eight seed marks | Denominators and synthetic-data caption remain visible |

Revision 2: reveal triggers are created after the desktop story pin and refreshed after fonts settle. An always-matching media condition enables reveals below the desktop breakpoint. Callback tweens are owned by the GSAP context for cleanup. Content is explicitly visible under the manual and OS reduced-motion settings. Horizontal motion is clipped at the main content boundary to prevent page overflow.

GSAP/Lenis follows the [official Lenis ticker integration](https://github.com/darkroomengineering/lenis#gsap-scrolltrigger) and [ScrollTrigger documentation](https://gsap.com/docs/v3/Plugins/ScrollTrigger/). References are technical guidance; library versions are locked in package-lock.json. Native touch scrolling is retained. No WebGL or decorative particle runtime is necessary for the selected direction.
