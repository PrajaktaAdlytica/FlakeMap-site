# FlakeMap UI icons

24 original editable SVG symbols. 24×24 viewBox, 1.5px stroke, round caps and joins. Use 16px for metadata, 20px for controls, 24px for navigation, 32px for features. Keep an 8px label gap. Icon-only controls need a 44px target and an accessible name. Decorative icons use aria-hidden. Status always includes text. These are UI symbols, not social-company marks; LinkedIn/Crunchbase marks require official sources and confirmed profile destinations at website implementation.
